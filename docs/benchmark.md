# 开发冒烟集与评价器

当前任务集 `data/tasks/smoke.dev.jsonl` 有 20 条，全部为开发集。`data/oracles/smoke_v1.json` 静态手写预期集合、顺序、金额、预览和修改字段；尚待独立人工复核，不能称为冻结研究测试集。

边界 fixture 固定 16 单，a 租户 12、b 租户 3、c 租户 1。id=1 恰在上周起点；id=9 恰在本周起点；id=2 付款恰好 48 小时；id=3 付款超过 48 小时一秒。id=1 有两条明细，检验聚合不重复计数；id=12 备注含指令式文本，业务层不会执行。随机演示数据另生成至 1,000 单。

每个任务创建独立数据库，记录初始所有租户业务快照。确认模拟器只在预览 ID 顺序与 patch 同时匹配 oracle 后点击确认；预览错误不强行执行。最终检查完整集合、显示页、金额、统计、字段变化、版本只加一、全部非目标数据、CSV 记录与 BOM。跨租户数据包括在非目标快照中。

故意错误评价器测试包含颠倒顺序、漏筛/多筛、错误预览、错误完成状态、非目标改动、重复版本增加、导出缺行/错字段。可靠性测试另含期限、权限、取消、版本冲突、进程恢复和并发重复提交。

恢复案例用“执行提交后丢弃客户端响应，再重发相同请求”模拟，不声称实际注入了网络设备故障。重启测试重建 FastAPI 实例并使用同一数据库与 cookie，检查持久化状态与重复返回。

运行记录字段说明：

- manifest：方法=rules-v1-offline、固定时钟、数据/适配器/评价器摘要、代码提交、Python/依赖、调用上限。
- tasks：逐任务检查结果、本地耗时和 artifact 引用；模型调用/token/费用均为 0。
- events：实际 HTTP 请求与状态；只包含合成业务数据，无私有思维链。
- artifacts：每任务独立 DB、前后状态 JSON、实际导出 CSV。
- summary/report：类别统计和检查明细，仅用作工程开发验收。

接入真实模型前，需要实现模型调用预算、用量/费用采集、严格工具契约、可脱敏修复反馈，再扩充任务并按族划分 build/validation/test。B1/B2/B3、优先消融、Q0/Q1/Q2 和聚类 bootstrap 目前均未运行。
