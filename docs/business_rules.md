# 业务口径 v1

## 身份与数据

- 合成系统分为 a/b/c 三租户。模型工具不接受 tenant_id/user_id/role。
- 本地演示身份：operator_a → a/operator；viewer_a → a/viewer；operator_b → b/operator。会话 cookie 为随机不透明 token，HttpOnly + SameSite Strict，12 小时过期。演示切换不是生产认证。
- 所有读取、结果集、预览、操作状态和导出受当前服务器会话归属约束。同租户不同会话也不能访问彼此结果/确认凭证。
- 金额 Numeric(12,2)，服务层 Decimal，JSON 返回定点字符串，CNY；前端只将其转换为显示格式，不参与业务计算。
- 五种状态 pending_payment / paid / shipped / completed / cancelled。优先级与复核标记不改变主状态。

## 时间、排序与指代

- Asia/Shanghai 为业务时区，UTC 带时区存储与比较。SQLite 取回时间后恢复 UTC 标识。
- 参考时间固定为 2026-10-26T12:00:00+08:00；上周为 [2026-10-19T00:00:00+08:00, 2026-10-26T00:00:00+08:00)。
- 默认筛选 created_at，明确“上周付款”时筛选 paid_at。
- 等待发货超过 N 小时：status=paid 且 shipped_at IS NULL，且 paid_at < reference_time - N hours；恰好边界排除。
- 金额或时间排序自动追加 id ASC；空日期排最后。默认 id ASC。
- 完整结果集包括所有命中 ID 与版本，分页只改变显示页面；默认 20，最大 100 条/页。
- “这些/其中”指当前明确结果集；勾选对象为当前页显式选中 ID；“第二条”指当前展示页第二个 ID。
- 追加过滤与原结果集取交集，不扩大集合。相同字段不同等值条件视为冲突并要求重新查询；金额/时间取更紧边界。
- 结果集有效期 30 分钟。继续筛选、分页、统计、导出及修改前校验版本；发现变化要求重新查询。
- 会话 context_version 单调递增；旧页面请求拒绝。新查询/翻页/勾选取消旧预览。

## 修改、确认和导出

- 仅 operator 可以修改 paid 且未发货订单的 priority / review_status；review_status 为 normal/pending_review。
- 一次修改 1–500 条，任何目标状态或版本不符则整体拒绝；不静默跳过或截断。
- 预览含完整 ID、版本、字段前后值、身份、页面版本及真实 UTC 到期时间。预览默认 5 分钟。
- 确认使用独立页面接口，校验服务器计算的 SHA-256 摘要；聊天“确认”不产生确认凭证。
- apply 再检查角色、状态、版本、摘要和期限，compare-and-swap 写入；操作、订单与审计在同一事务提交。
- 幂等键作用域是会话，并与预览和摘要绑定；相同键不同请求拒绝；同一预览不能换键重复执行。
- 业务成功后更新自身结果集的版本，保持集合成员不变，方便继续导出；其他会话结果集会因版本变化失效。
- 导出固定结果集内全部记录，不只当前页，也不把勾选对象误当完整结果。生成后持久化 CSV 内容及摘要，下载结果可跨进程恢复。
- 备注是数据，规则解析器从不将备注作为操作指令。没有 SQL/脚本/任意 HTTP 工具。

## 失败处理

空对象、过期、未授权、版本冲突、旧页面与未识别条件均返回明确状态，不伪报完成。修改成功之后的独立导出失败不撤销已完成修改。当前没有外部模型服务，不实现虚假的“模型修复”流程。
