# v0.3 功能扩展

本轮将原来的“订单列表 + 助手”扩展为订单列表、统计看板和操作审计三个工作区，并保留共享的筛选、结果集、确认、幂等和租户边界。

[本轮验收与截图](features_v03_verification.md)：64项后端检查和10条浏览器流程通过；4项 PostgreSQL 检查跳过。

## 1. 高级组合筛选

在订单列表展开“高级筛选”，可以组合：

- 订单编号、客户名称、商品名称和商品分类。
- 多个城市、多个订单状态、金额上下限。
- 优先处理/普通优先级、正常/待复核。
- 创建时间、付款时间的起止范围和等待发货小时数。

多选同一字段采用“或”，不同字段采用“且”。选择多个城市/状态时，界面会清除上方对应的单选条件。商品名称与分类同时指定时，要求同一个订单明细中的商品同时满足两者；查询使用存在性条件，避免一单多件商品导致重复订单。

字符串查询按字面包含匹配，百分号和下划线不会变成任意通配符。时间统一按上海时区展示，终点不包含在范围中。完整条件显示在筛选摘要中，点击筛选不会丢失不在基本输入框中的条件。

快捷工作队列提供待发货、超过48小时、优先处理和待复核入口。它们会发起明确的新查询，并更新当前结果集。

## 2. 常用查询

点击“保存当前查询”，保存**已经应用**的条件、排序和每页数量；输入框中尚未应用的草稿不会被保存。

查询按租户和操作者私有保存，可以应用、重命名和移除。退出当前会话再用同一演示身份登录仍然存在；切换其他身份看不到。应用时重新查询最新业务数据，不复用过期结果集或保存旧订单 ID。翻页位置重置到第一页，日期条件保留原来的绝对范围。

名称重复会给出提示；重命名和移除检查记录版本。移除只影响个人查询配置，不删除或修改订单。只读用户也可以管理自己的常用查询。

## 3. 完整订单详情

点击订单编号，可以看到：

- 订单金额、状态、客户、收货城市、时间和处理标记。
- 每条商品明细的名称、分类、数量、单价和小计。
- 已存在的模拟物流公司、运单号和发货时间；没有记录时明确显示暂无。
- 原始订单备注及最近的字段修改记录。

备注仅作为文字展示，不作为指令执行。客户、商品、物流和审计查询均校验当前租户。详情只展示实际保存的时间与字段，不生成不存在的物流轨迹或完成时间。

## 4. 统计看板与钻取

统计范围可选择当前完整结果集或当前租户全部订单。看板包含订单数量/总额/平均订单金额、已付款金额、待付款金额、待发货/超时/优先/复核队列，城市与状态分布，最近7/14/30天趋势，以及待发货时长分布。

金额在后端用 Decimal 计算，统计按订单去重。平均订单金额为当前范围内全部订单总额除以订单数；已付款金额覆盖 paid/shipped/completed 状态。趋势按上海时区的创建日期归组，窗口以固定业务参考时刻计算。其他指标覆盖完整统计范围。

时长分组边界为 ≤24、>24–48、>48–72、>72 小时，等待超过48小时采用严格大于判断。恰好48小时不会进入超时队列。

点击城市、状态或队列卡片，可进入对应订单列表。当前结果集的钻取会在原集合上继续筛选；全租户范围的钻取发起新的查询。看板没有复用订单列表的导出按钮，避免把两种范围混淆。

助手侧栏会显示当前操作对象的订单数量。看板范围可独立设置；需要处理看板中的订单时，可先点击分组进入相应列表。

## 5. 操作审计

操作审计展示本租户真实提交的字段变更，包括订单、操作者、修改前后值、实际操作时间和关联操作编号。支持按订单/操作者筛选和分页；点击订单可查看详情中的修改记录。

审计时间使用实际系统时钟，与用于查询实验的固定业务时钟不同。初始种子数据不会伪造修改历史；取消预览和拒绝操作不会生成成功修改记录。同租户只读用户可以查看，跨租户不可见。切换身份后会重新加载页面数据，避免沿用前一个身份的统计或审计缓存。

## 助手示例

离线规则模式仍只覆盖明确句式，新增可试用：

```text
查询客户名称包含合成客户001的商品分类为数码的上海订单
查询商品名称包含商品01的订单
查询优先处理的订单
查询待复核的订单
查看这些订单统计看板
查看操作审计
查看订单4的修改记录
查看订单5的详情
```

查询会切换回订单列表，统计请求打开对应范围的看板，订单审计请求保留指定的订单编号。常用查询目前通过界面管理，不声称支持任意自然语言保存/重命名操作。
