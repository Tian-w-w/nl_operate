- FastAPI 查询、会话、预览、统计、导出和助手响应有明确 Pydantic schema；前端类型由实际 OpenAPI 生成。生成器遇到未知 schema 会失败，CI 检查类型文件是否漂移。
- 前端区分 401、服务异常和请求超时，服务错误不会自动创建操作员身份。

## 模型调用与事务

请求被拆成三个阶段：

```text
短事务 A：认证、校验上下文、预占预算、提交 RECEIVED 计划和 RUNNING 调用记录
无数据库事务：规则解析或模型网络调用
短事务 B：重新认证、检查页面版本和期限、验证动作、执行业务、保存终态与用量
```

模型等待期间，其他请求可以继续查询或改变页面；旧解析返回时若 context_version 已变，会记录 STALE_CONTEXT，不能覆盖新结果或修改旧目标。

模型动作由独立的 Action schema 校验，只能提出已注册操作。身份、租户和确认状态不属于可生成字段。业务修改继续使用原有预览、页面确认、版本检查、事务和幂等保护。

解析开始前的记录已提交，进程中断不会完全丢失任务。会话再次访问时，过期 RUNNING 调用变为 UNKNOWN，未执行计划记录为 FAILED。此机制负责识别中断，**没有实现复杂多步骤任务的自动接管与续跑**；不会自动重放修改。

## 模型接口与预算

支持 OpenAI Responses 的严格函数提案，固定工具为 propose_action；不向模型注册 apply/confirm 工具。调用 store=false，不进行自动重试，不上传 oracle、认证 token 或订单备注。

默认 `.env.example` 的 MODEL_ADAPTER=rules、MODEL_CALLS_ENABLED=false，真实调用关闭。启用需显式配置模型标识、后端 API key、输入/输出费率、单会话预算和全项目预算；启动会校验配置。原始密钥不会出现在 Settings repr、调用接口或结构化日志中。

每个会话有调用次数与费用额度，项目预算跨所有会话共享；切换演示身份不能重新获得项目预算。数据库行锁串行化预算预占。项目额度作用于当前数据库内累计调用，没有隐式每日重置。

调用前按序列化输入 UTF-8 字节数及输出上限保守预占；成功后用 provider 返回 token 数与配置费率计算估算费用。该数值不是供应商账单，错误费率、供应商额外计费或协议变化会影响估算。超时/缺失用量时保留预占额，不记为免费。

每次记录 request_id、plan_id、适配器/模型、耗时、token、估算/预占费用、错误码、输入/响应摘要。`GET /api/model-usage` 查询当前会话用量，助手消息也显示单次耗时与用量。HTTP 日志不打印请求正文、cookie 或密钥。

接口依据：[OpenAI 官方函数调用说明](https://developers.openai.com/api/docs/guides/function-calling?api-mode=responses)。本轮只使用 httpx.MockTransport 验证协议、错误和预算，**未以真实密钥联调、未发生付费调用，也没有真实模型效果成绩**。
